minimax-add
-----------

JAX reproduction of **Adversarial Environment Design via Regret-Guided
Diffusion Models** (Chung et al., 2024), built on top of
[minimax](https://github.com/facebookresearch/minimax) (Jiang et al., 2023).

This is a fork of minimax that adds:

- Modern JAX compatibility (JAX >= 0.6, distrax replacing tfp)

- The ADD algorithm (`minimax.add`) including DDPM/DDIM diffusion, an
  environment critic, and regret-guided level sampling for the maze domain

The original minimax code is available under Apache 2.0 license.


## Installation

Requires Python >= 3.12.

```bash
git clone <this-repo>
cd minimax-add
pip install -e .

# For TPU support
pip install jax[tpu]
```


## Training

The reproduction has four training entrypoints: a diffusion generator
and three RL configurations (a DR baseline, a diffusion-sampled
baseline, and the full regret-guided method). Each runs on a single
TPU chip (or GPU/CPU) by default; diffusion pretraining optionally
pmaps over multiple chips.

All scripts accept `--help` for the full argument list. The defaults
below match the configuration we used to reproduce the paper (within
~18pp at full ADD — see `reports/` in the parent workspace if you have
access).

### Diffusion pretraining

Train a DDPM on procedurally generated 13×13 maze levels. ~300k steps,
saves checkpoints to `checkpoints/diffusion/`.

```bash
# Single-chip
python -m minimax.add.train_diffusion --num_heads 4

# Multi-chip (recommended; ~4x faster on 4 TPU chips)
python -m minimax.add.train_diffusion --num_heads 4 \
    --ckpt_dir checkpoints/diffusion/
```

`--num_heads 4` fixes the UNet attention head count to match the PyTorch
reference. Without it, the UNet uses a legacy `max(1, channels//64)` rule
(needed only for loading older checkpoints).

Each `--sample_every` steps the script samples 64 levels and prints
solvable-fraction and wall-count distribution. Final checkpoint is saved
as `checkpoints/diffusion/final.pkl`.

#### Skipping pretraining: use an existing checkpoint

Pretraining takes a long time (~20h on one chip, faster on multiple).
You can skip it for the RL entrypoints below by passing
`--diffusion_ckpt <path>` to any pretrained checkpoint. Older
checkpoints (v1–v3 in our workspace) were trained without
`--num_heads 4`; load them with the **default** UNet config and
**omit** `--unet_num_heads` from the RL command. Checkpoints trained
with `--num_heads 4` require `--unet_num_heads 4` — mismatch produces
silent garbage (parameter shapes match, semantics differ).

### DR baseline

PPO with levels generated by minimax's random wall-placement procedure
(no diffusion model). This is the standard DR baseline reported in the
paper. Note `--n_walls 60` — the paper's DR baseline uses up to 60
walls, not the env-default 25.

```bash
python -m minimax.add.train_rl \
    --runner dr \
    --n_walls 60 \
    --gae_lambda 0.98 \
    --entropy_coef 1e-3 \
    --n_updates 30000 \
    --eval_every 100 \
    --eval_episodes 100 \
    --ckpt_every 1000 \
    --log_every 50 \
    --seed 0
```

`gae_lambda=0.98, entropy_coef=1e-3` are minimax's paper hyperparameters
for DR (Jiang et al. 2023 Table 4); the diffusion-based RL entrypoints
use the script-default `gae_lambda=0.95, entropy_coef=0.0`.

### Diffusion without guidance baseline

PPO with levels sampled unconditionally from the diffusion model.
This is the natural ablation of ADD — the `--runner add` flag uses the
ADDRunner but with `omega=0` (no regret guidance).

```bash
python -m minimax.add.train_rl \
    --runner add \
    --diffusion_ckpt checkpoints/diffusion/final.pkl \
    --n_updates 30000 \
    --eval_every 100 \
    --eval_episodes 100 \
    --ckpt_every 1000 \
    --log_every 50 \
    --seed 0
```

### Regret-guided diffusion

The full ADD method: joint training of PPO + an environment critic,
with the critic's regret gradient steering DDIM sampling.

```bash
python -m minimax.add.train \
    --diffusion_ckpt checkpoints/diffusion/final.pkl \
    --n_updates 30000 \
    --eval_every 100 \
    --eval_episodes 100 \
    --seed 0
```

Guidance strength `--omega` defaults to `5.0` and switches on once the
critic buffer (capacity 1600 levels) is full; before that omega is forced
to 0 (unguided) so the critic has time to learn from a representative
sample.


## Metrics

All three RL training entrypoints print the same metrics every
`--eval_every` updates:

- **Mean solved rate** on a fixed 12-environment test set (defined as
  `EVAL_ENV_NAMES` in `train.py` / `train_rl.py`): FourRooms, SixteenRooms,
  SixteenRooms2, Labyrinth, Labyrinth2, StandardMaze, StandardMaze2,
  StandardMaze3, SmallCorridor, LargeCorridor, Crossing, PerfectMaze.
- **Per-env solved rate**, one line each.
- **Complexity of the most-recent training batch of levels**: mean wall
  count, mean shortest-path length (over passable levels), and passable
  ratio. For the regret-guided entrypoint you can watch path-length climb
  as guidance strengthens — the paper reports it going from ~10 → ~45
  over training.

Diffusion pretraining separately logs sampled-level solvable fraction
and wall count every `--sample_every` steps.

`--eval_episodes 100` is what we use for final reporting (matches the
paper); `10` is fine for quick iteration.


## Package structure

```
src/minimax/
  add/                  ADD implementation
    runner.py           ADDRunner (extends DRRunner)
    unet.py             Denoising UNet for DDPM
    diffusion.py        DDPM forward process, DDIM sampling
    theta.py            Level encoding/decoding (maze <-> image)
    guidance.py         Regret-guided DDIM sampling
    critic.py           Distributional environment critic
    train.py            Regret-guided training loop (full ADD)
    train_rl.py         Diffusion-no-guidance and DR training loop
    train_diffusion.py  Diffusion pretraining loop
  runners/              Minimax UED runners (DR, PLR, PAIRED, ...)
  envs/                 JAX environments (maze, ...)
  models/               RL model architectures
  agents/               PPO agent
```
